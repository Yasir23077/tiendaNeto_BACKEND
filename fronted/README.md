# NETO Ventas

Frontend de React + Vite para el sistema de ventas de Tiendas NETO.

## Iniciar

```bash
npm install
npm run dev
```

El frontend utiliza el backend Spring Boot en `http://localhost:8080`; Vite reenvía automáticamente las rutas `/api`.

La guía detallada de carpetas, archivos, funciones y reglas del sistema está en [DOCUMENTACION_DETALLADA_PROYECTO_NETO.md](../servicioo/DOCUMENTACION_DETALLADA_PROYECTO_NETO.md). Los archivos de lógica también incluyen comentarios junto a sus funciones principales.
